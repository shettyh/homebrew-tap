# homebrew-tap

Official Homebrew tap for [rem](https://github.com/shettyh/rem) — local-first spaced repetition across desktop, terminal, and iPhone.

## Install (macOS)

```sh
brew install --cask shettyh/tap/rem
```

This single installation installs `/Applications/rem.app` (signed & notarized) and links the bundled `rem` CLI onto your `PATH`. In-app updates keep both the desktop app and CLI updated together.

`Casks/rem.rb` is updated automatically by `shettyh/rem`'s release workflow.
